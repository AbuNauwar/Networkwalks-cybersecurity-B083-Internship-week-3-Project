week 3 is also another milestone in my cybersecurity and Ethical hacking experience, in this week project i was exposed to cracking of password using the following tools.

1. John the ripper
2. Johnny GUI
3. online Hash cracker.
   
using above tools i was able to successfully cracked three different PDF files. (see attached screenshots).
Thanks to waqaskareem and the entire staff of#networkwalks for their tireless effort and commitment to wards this internship program.

below are the steps followed
1. Download John the ripper from the official wensite
2. Download johnny GUI
3. Extract and install Johnny GUI
4. Open Johnny GIU
5. Select Setting and click on browse
6. Locate john.exe from its location and click open
7. Locate the encrypted PDF file
8. visit https://www.onlinehashcrack.com/
9. Click on Browse and upload the encrypted PDF file
10. Copy the output of the hashing and save it in a notepad file with name hash1
11. open johnny GUI
12. Click on password file
13. upload the hash file
14. click on start new attack
15. Password is finally cracked
